# Images Directory

This directory contains static images for the BepHue website.

## Required Images

### Hero Section
- **hero-bg.jpg** (1920x1080px or larger)
  - Main hero background image
  - Should showcase restaurant ambiance or signature dish
  - High quality, professionally shot

### Features Section
- **feature-1.jpg** (1200x800px)
  - Traditional Hue cuisine dishes
  - Close-up food photography

- **feature-2.jpg** (1200x800px)
  - Fresh ingredients
  - Market-style or ingredient preparation shots

- **feature-3.jpg** (1200x800px)
  - Restaurant interior/ambiance
  - Comfortable seating, lighting, decor

### Menu Items
- Place dish photos in this directory
- Recommended size: 800x600px
- Format: JPG or PNG
- Naming: descriptive names (e.g., `bun-bo-hue.jpg`, `banh-khoai.jpg`)

### Gallery
- Various restaurant and food photos
- Minimum size: 1200x800px
- Format: JPG
- Naming: descriptive (e.g., `interior-1.jpg`, `food-platter.jpg`)

## Temporary Placeholders

Until you add real images, you can:

1. **Use Unsplash URLs** - Replace image paths with Unsplash URLs:
   ```
   https://images.unsplash.com/photo-1514933651103-005eec06c04b?w=1200
   ```

2. **Use placeholder services**:
   ```
   https://placehold.co/1200x800/dc2626/ffffff?text=BepHue
   ```

3. **Download free stock photos** from:
   - Unsplash (https://unsplash.com)
   - Pexels (https://pexels.com)
   - Search for: "Vietnamese food", "restaurant interior", "Hue cuisine"

## Image Optimization Tips

- Use Next.js Image component (already implemented)
- Keep file sizes under 500KB
- Use WebP format when possible
- Compress images before upload
- Maintain aspect ratios for consistency
