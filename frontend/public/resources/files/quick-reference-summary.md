# Bep Hue - Quick Visual Identity Summary

## 🎨 Core Color Palette

```css
/* Copy-paste ready */
--signature-red: #D44638;    /* Primary brand color, CTAs, logo */
--warm-cream: #F5EBD9;       /* Backgrounds, cards, warmth */
--rich-brown: #4A3829;       /* Text, furniture, grounding */
--terracotta: #C67946;       /* Warm accents, walls */
--ceramic-blue: #2F4F6F;     /* Traditional details */
--herb-green: #7CB342;       /* Freshness, vegetables */
--bamboo-gold: #D4A574;      /* Natural materials */
--warm-white: #FFFFFF;       /* Clean spaces */
--charcoal: #2C2C2C;        /* Dark text */

```

---

## 📐 Design Principles

1. **Warm & Inviting** - Earth tones, never cold or clinical
2. **Traditional Materials** - Bamboo, wood, ceramic, banana leaves
3. **Imperial Heritage** - Connection to Hue's royal cuisine
4. **Refined Rustic** - Elegant but authentic, never pretentious
5. **Atmospheric** - Intimate lighting, cozy spaces

---

## 🖋️ Typography

**Headings:** Serif font (elegant, refined)
- Playfair Display or Cormorant recommended

**Body:** Clean sans-serif (readable, warm)
- Inter, Nunito Sans, or Open Sans

**Must Support:** Vietnamese diacritics (Bún, Bánh, Hến)

---

## 📱 Component Quick Guide

### Navigation
- Background: `#F5EBD9` (cream)
- Text: `#4A3829` (brown)
- Active: `#D44638` (red underline)

### Buttons
- Primary: Red `#D44638` background, white text
- Secondary: Cream `#F5EBD9` background, brown text

### Cards (Menu Items)
- Background: `#F5EBD9` (cream)
- Border: `#D4A574` (bamboo gold) - subtle
- Shadow: Soft, warm

### Footer
- Background: `#4A3829` (dark brown)
- Text: `#F5EBD9` (cream)
- Links: `#D44638` (red)

## 📏 Responsive Breakpoints

- **Mobile:** 375px - 767px (1 column)
- **Tablet:** 768px - 1023px (2 columns)
- **Desktop:** 1024px+ (3 columns)

---

## ✨ Animation Guidelines

- **Speed:** 300ms transitions (smooth, never jarring)
- **Hover:** Scale 1.05x, add warm glow shadow
- **Fade-ins:** Gentle, organic
- **Scroll:** Subtle parallax on backgrounds
- **CTA:** Gentle pulse on red buttons

---

## 🚫 What to Avoid

❌ Pure white backgrounds (too clinical)
❌ Cool blue tones (except ceramic accents)
❌ Sharp geometric shapes (prefer organic)
❌ Fast/jarring animations
❌ Generic "Vietnamese" stereotypes
❌ Modern minimalism without warmth

---
