## 🎯 Project: BepHue Restaurant Website

This document provides context for Claude Code (AI assistant) to help with development tasks.

## 📋 Project Summary

**What:** Full-stack restaurant website for "BepHue" - a Vietnamese restaurant specializing in Hue cuisine  
**Tech Stack:** Next.js 14+ (TypeScript) + Strapi CMS  
**Design Reference:** https://sushimasa.vn/ (similar layout and features)  
**Current Status:** Initial project structure created, ready for implementation

## 🏗️ Architecture

```
Frontend (Next.js) ←→ REST API ←→ Backend (Strapi CMS)
     Port 3000                        Port 1337
```

### Frontend Stack

- **Framework:** Next.js 14+ with App Router
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Forms:** React Hook Form + Zod validation
- **State:** React hooks (no Redux needed for this project)

### Backend Stack

- **CMS:** Strapi (headless CMS)
- **Database:** SQLite (dev), PostgreSQL (prod)
- **API:** REST API auto-generated by Strapi

## 🔧 Common Development Tasks

### Creating a New Page

```bash
# 1. Create page file
touch frontend/app/[page-name]/page.tsx

# 2. Add to navigation in components/layout/Header.tsx
```

### Creating a New Component

```bash
# 1. Create component file
touch frontend/components/[category]/ComponentName.tsx

# 2. Export from component
export default function ComponentName() { ... }

# 3. Import where needed
import ComponentName from '@/components/[category]/ComponentName'
```

### Fetching Data from Strapi

```typescript
// Use the strapi.ts utility
import { getMenuItems } from "@/lib/api/strapi";

// In page or component
const items = await getMenuItems();
```

### Adding a New API Endpoint

```typescript
// In lib/api/strapi.ts
export async function getNewData() {
  try {
    const response = await fetchAPI("/endpoint?populate=*");
    return response.data;
  } catch (error) {
    console.error("Error:", error);
    return [];
  }
}
```

## 💡 Coding Conventions

### File Naming

- **Components:** PascalCase (`Header.tsx`, `MenuCard.tsx`)
- **Utilities:** camelCase (`strapi.ts`, `utils.ts`)
- **Pages:** lowercase (`page.tsx`, `layout.tsx`)

### Component Structure

```typescript
'use client'; // Only if using hooks/interactivity

import { ... } from '...'

interface Props {
  // Props type
}

export default function ComponentName({ prop }: Props) {
  // Hooks
  // Handlers
  // Render
  return (
    <div className="...">
      {/* JSX */}
    </div>
  )
}
```

### Styling Approach

- Use Tailwind utility classes directly
- Avoid custom CSS unless absolutely necessary
- Use Tailwind config for custom colors/fonts
- Responsive: `md:`, `lg:` prefixes

### Data Fetching

- Use Server Components by default (no 'use client')
- Add 'use client' only when needed (hooks, interactions)
- Cache API responses in production
